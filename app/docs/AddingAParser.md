# Agregar un Parser

1. Crear archivo en `src/performance_decision_engine/parsers/`.
2. Recibir una ruta `Path`.
3. Validar existencia y formato.
4. Devolver una estructura explícita.
5. No aplicar reglas de negocio.
6. Agregar pruebas en `tests/`.

La conversión al dominio puede realizarse en `adapters/`.
