# H6 - Decision Matrix

## Objetivo

Implementar la matriz de decisión propuesta para el proyecto.

## Evolución

La tripleta actual constituye la primera versión del modelo de decisión.

Posteriormente evolucionará hacia una matriz más amplia incorporando nuevas variables.

## Variables iniciales

- Concurrency
- Iterations
- Response Time

## Variables futuras

- Apdex
- Error Rate
- Ramp Up
- Duración
- Cantidad de Usuarios
- Criticidad
- Complejidad

## Resultado

Recomendación automática de configuración.
