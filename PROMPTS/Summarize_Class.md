# Prompt — Consolidar asignatura

## Objetivo
Transformar transcripciones, PPT y materiales en un documento por asignatura.

## Prompt
Analiza exclusivamente los archivos entregados. Genera un resumen estructurado con objetivos, conceptos, algoritmos, herramientas, laboratorios, bibliografía, relaciones con otras asignaturas y aplicación al Capstone. Diferencia claramente hechos, inferencias y contenido pendiente. No inventes conceptos no presentes.

## Salida
Markdown siguiendo `TEMPLATES/Class_Template.md`.
