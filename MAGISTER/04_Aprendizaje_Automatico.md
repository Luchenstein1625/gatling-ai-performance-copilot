# 04 — Aprendizaje Automático

## Objetivo
Comprender y aplicar métodos supervisados, no supervisados y de refuerzo para resolver problemas de clasificación, agrupamiento y predicción.

## Temas consolidados
- EDA.
- Preparación de datos.
- Train/test split.
- Validación cruzada.
- Balanceo de clases.
- Underfitting y overfitting.
- KNN.
- Naive Bayes.
- SVM.
- Árboles de decisión.
- Random Forest.
- K-Means.
- K-Modes.
- K-Prototypes.
- Fuzzy C-Means.
- DBSCAN.
- Apriori.
- Q-Learning.

## Métricas
- Accuracy.
- Precision.
- Recall.
- F1.
- ROC-AUC.
- MAE.
- RMSE.
- MSE.
- R².
- MAPE.

## Aporte al Capstone
Es la base del motor de recomendación de cuadrantes.

## Aplicación directa
- Clasificación supervisada si existen etiquetas expertas.
- Clustering si no existen etiquetas.
- Detección de patrones históricos.
- Comparación de modelos.
- Optimización de hiperparámetros.
- Evaluación frente a baseline.

## Modelos candidatos
- Árbol de decisión por explicabilidad.
- Random Forest por robustez.
- KNN por similitud histórica.
- Clustering para descubrir perfiles.
- Reglas expertas como baseline.
- Q-Learning como posible trabajo futuro.
