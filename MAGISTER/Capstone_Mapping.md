# Mapeo de asignaturas al Capstone

| Asignatura | Aporte principal |
|---|---|
| Introducción IA | fundamentos de inteligencia y adaptación |
| Representación de Conocimientos | reglas, taxonomías y explicabilidad |
| Búsqueda y Heurísticas | selección de configuraciones |
| Aprendizaje Automático | recomendación y evaluación |
| Agentes Inteligentes | arquitectura y orquestación |
| Computer Vision | análisis visual opcional |
| PLN | generación e interpretación |
| Tópicos Emergentes | LLM, RAG, agentes y automatización |
| Deep Learning | fundamentos de modelos generativos |
| Taller de Diseño | validación de problema y usuarios |
| Simulación Basada en Agentes | escenarios y sensibilidad |
| Tópicos Avanzados I | métricas, umbrales y desbalance |
| Tópicos Avanzados II | pendiente |

## Integración mínima recomendada
El MVP debería demostrar uso explícito de:
- Aprendizaje Automático;
- PLN;
- Agentes Inteligentes;
- Taller de Diseño;
- Tópicos Emergentes;
- Tópicos Avanzados I.
