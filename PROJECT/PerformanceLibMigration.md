# Migración de `performance-lib`

## Rol
La migración parcial de Java a Python puede ser un habilitador técnico del Capstone.

## No es el aporte principal
La reescritura de lenguaje es ingeniería de software. El aporte de IA aparece al recomendar, explicar, aprender y evaluar.

## Componentes a migrar
- parser de `performance.yaml`;
- parser de valores maestros;
- validación;
- resolución de parámetros;
- parser Gatling;
- normalización;
- integración con recomendador.

## Validación
Comparar Java y Python con las mismas entradas y verificar equivalencia.
