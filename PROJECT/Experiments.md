# Experimentos

## EXP-001 — Generación de script Gatling

### Objetivo
Medir si la IA generativa produce scripts válidos y útiles.

### Métricas
- tasa de compilación;
- errores por script;
- correcciones manuales;
- tiempo de generación;
- tiempo total hasta ejecución.

### Baseline
Script creado manualmente.
