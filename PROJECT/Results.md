# Resultados

Este documento se completará durante P2 y P3.

## Estructura esperada

### Resultados de datos
- cantidad de microservicios;
- cantidad de ejecuciones;
- cobertura histórica;
- calidad de datos.

### Resultados del generador
- compilación;
- correcciones;
- tiempo;
- calidad percibida.

### Resultados del recomendador
- métricas de clasificación o clustering;
- comparación con expertos;
- sensibilidad;
- robustez.

### Resultados operativos
- tiempo ahorrado;
- reducción de trabajo manual;
- adopción;
- utilidad.

### Limitaciones
- dataset;
- generalización;
- ambientes;
- sesgos;
- dependencia de expertos.
