# Objetivos

## General
Diseñar y validar un sistema inteligente que automatice la generación de pruebas Gatling y recomiende dinámicamente el cuadrante de cada microservicio usando su historial.

## Específicos
1. Caracterizar el proceso actual.
2. Generar scripts Gatling con IA.
3. Definir cuadrantes cuantitativos.
4. Consolidar historial.
5. Implementar recomendación.
6. Comparar contra proceso manual.
7. Medir impacto técnico y productivo.
