# Problema de Negocio

La preparación de pruebas de rendimiento para microservicios depende de trabajo manual y conocimiento especializado. Los parámetros de carga no siempre consideran el historial de cada microservicio.

## Consecuencias
- baja estandarización;
- tiempos elevados;
- criterios variables;
- cargas poco representativas;
- escasa trazabilidad;
- análisis manual.

## Pregunta preliminar
¿Cómo reducir el esfuerzo manual y mejorar la consistencia de las pruebas de rendimiento usando IA generativa e historial Gatling?
