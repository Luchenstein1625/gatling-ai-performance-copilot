# P90

## Definición
El 90 % de las respuestas se encuentra bajo este tiempo.

## Interpretación
Métrica frecuente de servicio.

## Aplicación al Capstone
Candidata para reglas de cuadrantes.

## Fórmula o cálculo
Debe documentarse de forma explícita cuando corresponda.

## Riesgos
- interpretación aislada;
- comparación entre ejecuciones no equivalentes;
- tamaño de muestra insuficiente;
- promedios que ocultan colas o clases minoritarias.

## Recomendación
Usar esta métrica junto con otras medidas complementarias y registrar contexto de ambiente, versión y perfil de carga.
