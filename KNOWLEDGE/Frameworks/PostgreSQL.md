# PostgreSQL

## Definición
Base de datos relacional.

## Aplicación al Capstone
Persistencia estructurada de ejecuciones y metadatos.

## Fortalezas
Buena opción para trazabilidad.

## Riesgos o limitaciones
- complejidad innecesaria;
- dependencia tecnológica;
- costo;
- privacidad;
- dificultad de mantenimiento;
- incorporación sin evidencia de valor.

## Estado
Tecnología candidata o de referencia. Su adopción debe registrarse mediante una decisión formal.
