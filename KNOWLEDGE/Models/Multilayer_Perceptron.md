# Multilayer Perceptron

## Definición
Red neuronal feed-forward con varias capas densas.

## Aplicación al Capstone
Modelo alternativo para clasificación tabular si existe suficiente información.

## Ventajas
Captura relaciones no lineales.

## Limitaciones
Menor explicabilidad y necesidad de ajuste.

## Rol propuesto
Debe justificarse si el modelo se utiliza para generación, clasificación, extracción, representación o análisis temporal.

## Evaluación
- calidad técnica;
- robustez;
- latencia;
- costo;
- explicabilidad;
- privacidad;
- comparación con alternativas más simples.

## Estado
Concepto o candidato; no implica adopción definitiva.
