# Transformer

## Definición
Arquitectura basada en mecanismos de atención que procesa relaciones entre elementos.

## Aplicación al Capstone
Fundamento de LLM usados para generar scripts y explicaciones.

## Ventajas
Paralelismo, contexto amplio y transferencia.

## Limitaciones
Costo, opacidad y dependencia de datos.

## Rol propuesto
Debe justificarse si el modelo se utiliza para generación, clasificación, extracción, representación o análisis temporal.

## Evaluación
- calidad técnica;
- robustez;
- latencia;
- costo;
- explicabilidad;
- privacidad;
- comparación con alternativas más simples.

## Estado
Concepto o candidato; no implica adopción definitiva.

## Relación con el Magíster
Deep Learning, PLN, Computer Vision y Tópicos Emergentes, según corresponda.

## Próximos pasos
- vincular papers;
- definir experimento;
- documentar datos y métricas;
- registrar una decisión formal si se adopta.
