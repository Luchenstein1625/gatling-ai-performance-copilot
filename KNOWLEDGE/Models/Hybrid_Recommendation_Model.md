# Hybrid Recommendation Model

## Definición
Modelo que combina reglas, similitud histórica y aprendizaje automático.

## Aplicación al Capstone
Recomendar cuadrantes con controles de seguridad y explicación.

## Ventajas
Equilibra conocimiento experto y evidencia de datos.

## Limitaciones
Requiere definir precedencia, conflictos y calibración.

## Rol propuesto
Debe justificarse si el modelo se utiliza para generación, clasificación, extracción, representación o análisis temporal.

## Evaluación
- calidad técnica;
- robustez;
- latencia;
- costo;
- explicabilidad;
- privacidad;
- comparación con alternativas más simples.

## Estado
Concepto o candidato; no implica adopción definitiva.

## Relación con el Magíster
Deep Learning, PLN, Computer Vision y Tópicos Emergentes, según corresponda.
