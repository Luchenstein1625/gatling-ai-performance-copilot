# Fase 3B — Algorithms and Models

Esta entrega amplía la Knowledge Base con algoritmos de ML, optimización, evaluación y modelos de Deep Learning.

## Incluye
- clasificación;
- clustering;
- anomalías;
- reglas;
- aprendizaje por refuerzo;
- validación y optimización;
- Transformer, GPT, BERT y redes neuronales;
- modelos híbridos.

## Uso
Descomprimir sobre la raíz del repositorio. Los archivos se ubican en:
- `KNOWLEDGE/Algorithms/`
- `KNOWLEDGE/Models/`

## Regla
Los documentos describen candidatos. La adopción de un algoritmo o modelo debe quedar registrada en `DECISIONS/`.
