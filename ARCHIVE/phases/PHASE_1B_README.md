# Fase 1B — Gobierno documental, plantillas y operación

Esta entrega complementa la Fase 1A. Debe descomprimirse sobre la raíz del mismo repositorio.

## Incluye

- plantillas para papers, conceptos, clases, experimentos y prompts;
- biblioteca inicial de prompts;
- documentos operativos para reuniones y seguimiento;
- secciones adicionales de proyecto;
- preparación inicial de defensa;
- registros de decisiones adicionales;
- archivos de control para la siguiente fase.

## Cómo aplicar

1. Copiar el contenido sobre el repositorio creado con la Fase 1A.
2. Revisar colisiones antes de sobrescribir.
3. Ejecutar:

```bash
git add .
git commit -m "docs: agregar fase 1B de gobierno documental"
git push
```
